03 — The builds

What I Built Because of It

★ Featured project
PhishGuard
// why: I wanted to automate Tier 1 triage, not just read about it.
A Python CLI tool for SOC analysts that automates Tier 1 phishing email triage — parsing .eml files, validating authentication chains, enriching IOCs via threat intel APIs, and generating SIEM-ready reports. Offline by default; external enrichment requires explicit consent.
View on GitHub ↗
What it does
  • Parses .eml files — headers, Reply-To chain, HTML body URLs, attachment metadata
  • Validates SPF, DKIM, DMARC from headers + live DNS record lookups
  • Extracts IOCs — URLs, IPv4s, display-link vs destination mismatches
  • Enriches IPs via AbuseIPDB and URLs via VirusTotal when API keys are set
  • Weighted risk scoring — LOW / MEDIUM / HIGH / CRITICAL with explainable findings
  • Outputs text, JSON, HTML, CEF, and CSV — SIEM-ready out of the box
  • Batch triage mode + standalone URL/domain analysis with typosquatting detection

// Diagnostics tool
Shuri
// why: one question, answered fast — what is the health of this workstation right now?
A fast, open-source workstation diagnostics CLI for IT support and security teams — a portable first-response toolkit with no agents and no monitoring overhead. It sits where my day job and my SOC work meet.
View on GitHub ↗
What it does
  • Checks CPU, memory, disk, network, battery, and Windows AV posture in one scan
  • Physical drive health — reliability counters and operational state via Windows-native data
  • Transparent scoring: every deduction shown explicitly — 100 minus deductions = health score
  • History tracking — retains last 50 assessments; shuri compare diffs any two
  • Exports terminal, JSON, HTML, and Markdown reports with --redact for safe sharing
  • Builds a standalone Windows .exe — no Python required on target workstation
  • Concurrent 4-worker scan with live progress; each diagnostic reports its own duration
